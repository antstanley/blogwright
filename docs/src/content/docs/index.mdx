## Pick your app type

<CardGrid>
  <Card title="Static site" icon="document">
    Astro, SvelteKit prerendered, or any `pnpm build` that writes HTML. Served
    from a private S3 bucket through CloudFront. Nothing extra to configure.
  </Card>
  <Card title="Single-page app" icon="window">
    Add `"spa": true`. Unknown paths serve your `index.html`, so client-side
    routing works on refresh. See [Single-page apps](/guides/single-page-apps/).
  </Card>
  <Card title="Server-rendered app" icon="server">
    Add an `ssr` block. The build ships as a Lambda Web Function behind the same
    CloudFront distribution - Astro, SvelteKit, Nuxt, TanStack Start or Next. See
    [Server-rendered sites](/guides/server-rendered-sites/).
  </Card>
</CardGrid>

## Built in

<CardGrid>
  <Card title="Builds in a Lambda MicroVM" icon="rocket">
    `pnpm install && pnpm build` runs in an isolated MicroVM. Only changed files
    upload, and only changed paths are invalidated.
  </Card>
  <Card title="PR previews and CI deploys" icon="github">
    Static sites and SPAs get a subdomain per pull request. GitHub OIDC deploy
    roles mean CI never stores AWS keys.
  </Card>
  <Card title="Rollback and history" icon="right-caret">
    `blogwright rollback <hash>` re-deploys any earlier build. `history`, `logs`
    and `status` cover the rest.
  </Card>
  <Card title="Plugins" icon="puzzle">
    Add [traffic analytics](/plugins/analytics/) or
    [standard.site publishing](/plugins/standard-site/) when you need them.
  </Card>
</CardGrid>

## From zero to live site

```sh
pnpm add -D blogwright

pnpm exec blogwright init       # first-run wizard - writes config/production.jsonc
pnpm exec blogwright bootstrap  # create the infrastructure graph
pnpm exec blogwright deploy     # build in a MicroVM and publish
```

The [quickstart](/getting-started/quickstart/) walks every step, and the
[configuration reference](/reference/configuration/) covers everything beyond
the defaults. Reading by machine? Every page is Markdown - append `.md` to any
URL, or start from [/llms.txt](/llms.txt).
