## Steps

- [ ] Write `analytics-firehose-role` with `dependsOn: []`, creating the delivery role through `ctx.clients.iam.ensureRole` and applying its inline policy from a named helper shared by `create` and `update`, as `packages/cli/src/nodes.ts:180-216` does.
- [ ] Grant exactly the four capabilities the spec names, each against a concrete ARN built from `ctx.accountId`, the resolved analytics config and the recorded outputs of earlier nodes: Glue catalog read on the federated catalog, S3 Tables write on the table, `lambda:InvokeFunction` on the transform function ARN recorded by task 50, and `s3:PutObject` on the error prefix in the site's environment bucket — no fifth statement and no `*` resource.
- [ ] Write `analytics-firehose-stream` with `dependsOn: ['analytics-table', 'analytics-catalog-integration', 'analytics-transform-function']`, matching the ordering the spec's implementation notes state, and configure the Iceberg destination plus the record-transform Lambda processor pointing at the recorded function ARN.
- [ ] Point the error/backup prefix at the site's existing environment bucket (`ctx.names.bucket`) and add a comment stating why the cross-region write is accepted — the bucket is in `config.region` while the stream is pinned to `us-east-1`, and failed records are expected to be rare enough that the transfer cost is immaterial.
- [ ] Implement `read` to describe the stream and hydrate its delivery state into the plugin's scoped state, so task 54 can report health without a second describe path, returning `false` without throwing when the stream is absent.
- [ ] Implement `delete` to remove the stream and then the role, each idempotent, so a re-run after a partial teardown completes rather than failing on the already-deleted half.
- [ ] Extend `packages/analytics/src/nodes.test.ts`: assert the parsed policy document has four statements and no `*` resource; assert the stream's declared `dependsOn` set and its destination/processor payload; assert `read` surfaces the delivery state and returns `false` for an absent stream; assert a re-run of `delete` after a partial teardown issues the remaining call and throws nothing.
